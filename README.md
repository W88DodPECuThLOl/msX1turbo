# msX1turbo
Sharp X1turboでMSXを動かしてみる試み

# ビルド方法

## 必要な物
* SDCC
* HuDisk

## 手順
1. SDCC、HuDiskにパスを通しておきます。
1. makeLoader.batを実行します。
1. makeVdp.batを実行します。
1. makeVdpZ.batを実行します。
1. makeMsX1turbo.batを実行します。
1. makeMsX1turboZ.batを実行します。
1. makePackage.batを実行します。

以上

# 使い方

1. msX1turbo.d88を起動します。
2. ファイル選択画面から動かしたいのを選択します。
3. 動かなければ潔く諦めましょう！

以上

## 必須スペックについて

* ファイルサイズが32KiB以上の場合は、BANKメモリ0が必要です。
* ファイルサイズが32KiBより大きい場合は、EMM0が必要です。
* バンク切り替えを行っているものは、エミュレータの設定でできるだけ高速に実行できるようにしてください。

# ファイルについて
* 32KiB以下の場合は、そのままで拡張子をromにします。
* 32KiBより大きなファイルは、32KiBに分割します。
  * ファイル名は最初のは拡張子を「rom」にし、  
  次からのファイルは「001」「002」のように連番にします。
* IPS形式のパッチファイルは、適応するファイルの拡張子を「ips」にします。
